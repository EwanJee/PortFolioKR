summary: "지표 오류를 '설계가 가정한 데이터 계약이 실제 데이터와 맞는가'의 문제로 보고, 설계를 실제 데이터와 대조해 배포 전에 계약 8개 중 7개의 불일치를 찾아 고쳤습니다."
symptom: "설계한 지표를 실제 데이터에 돌려 보니 가입 후 7일 안 첫 구매율이 82~88%로 비현실적으로 높게 나왔고, 1회 구매자 약 49만 명이 잘못 분류됐습니다."
definition: "설계 단계부터, 문서가 가정한 데이터 계약(어떤 컬럼, 필터 조건, 사용자 키, 구매자 분류 규칙을 쓰는지)이 실제 데이터와 맞는지 검증하는 문제로 정의했습니다."
cause: "설계를 고칠 때마다 실제 테이블 구조와 값을 직접 조회해 다시 대조했고, 데이터 계약 8개 중 7개가 실제 데이터와 맞지 않았습니다. 7일 첫 구매율은 분모가 전체 가입자가 아닌 다른 기준으로 잡혀 부풀었고, 약 49만 명 오분류는 구매자 분류 규칙이 잘못돼 생겼습니다."
fix: "분모를 전체 가입자 기준으로 바로잡고 구매자 분류 규칙을 고치는 등 불일치 7개를 모두 고쳤습니다. 설계 문서를 고칠 때마다 실제 데이터 검사를 다시 돌려, 운영 적재까지 고친 오류가 다시 생기지 않았습니다."
prevention: "계산 결과 하나를 그대로 믿지 않고, 별도 AI 검토 도구로 보정값, 예측 모델, 계산식을 교차 검증하는 절차를 둡니다."
