# 화면 표시와 메뉴 이동 성능

확인 날짜: 2026-09-28. 메뉴 이동 비교 기준은 `db6e77a`의 운영 빌드와 `perf/instant-navigation`의 빌드다.

## 지연 원인

운영 사이트에서 문서가 브라우저 캐시에 있어도 화면 전환 효과는 약 0.3초 동안 이어졌다. 경력 행과 프로젝트 카드를 순서대로 표시하는 효과까지 끝나는 데는 각각 약 1.5초와 1.7초가 걸렸다. 클릭 후 문서 수신만 측정하거나 첫 방문의 Lighthouse 점수만 확인해서는 이 지연을 찾기 어렵다.

## 동작

- 주 메뉴의 HTML은 Astro의 `data-astro-prefetch="load"`로 미리 받는다. 낮은 우선순위로 진행하고 Astro의 오프라인, 데이터 절약, 느린 연결 제한을 따른다. 이미 받은 URL과 현재 URL은 중복 요청하지 않는다.
- `astro:before-swap`에서 화면 전환 효과를 생략하고 새 문서의 루트에 `data-instant-navigation`을 넣는다. 문서 교체, 방문 기록, 뒤로 가기, 접근성 안내는 ClientRouter가 처리한다.
- 메뉴로 이동한 본문, 카드, 경력 행, 타임라인 선과 섹션 선은 대기 없이 표시한다. 경력 숫자는 HTML에 있는 최종값을 유지한다.
- 처음 주소를 직접 열 때의 등장 효과와 숫자 효과, 홈 타이핑, 사용자가 조작하는 그림, 필터, 이미지 재생과 멈춤은 유지한다.
- 화면 전환 API가 없는 브라우저에서도 `fallback="swap"`으로 문서를 교체한다. 스크립트를 끄면 일반 링크와 정적 HTML이 동작한다.
- 공통 스타일과 글꼴 선언은 한 CSS 파일로 캐시한다. 홈 타이핑과 경력 숫자는 React 실행 코드가 필요 없는 커스텀 엘리먼트다. 움직이는 화면은 WebP로 배포하고 GIF 원본은 `src/assets/motion/`에 보관한다.

## 메뉴 이동 측정

Chrome에서 데스크톱 1440×900과 모바일 390×900을 측정했다. 네트워크 지연 150ms, 다운로드 200,000B/s, CPU 속도 4배 제한을 동일하게 적용했다. 각 기기의 새 브라우저 컨텍스트에서 홈을 연 뒤 3초 기다리고, 메뉴 6개를 두 차례씩 이동했다. 표는 기기 2개 × 이동 2회의 중앙값이다.

측정값은 클릭부터 문서 교체 후 화면 갱신 두 번, 화면 전환 효과, 유한한 등장 효과가 모두 끝날 때까지의 시간이다. 처음 글자가 보이는 시간과 구분한다.

| 메뉴 | 비교 기준 | 개선 결과 | 감소 |
| --- | ---: | ---: | ---: |
| 소개 | 868.5ms | 83ms | 90.4% |
| 경력 | 1,643ms | 86ms | 94.8% |
| 프로젝트 | 1,835.5ms | 100ms | 94.6% |
| 트러블슈팅 | 901ms | 75.5ms | 91.6% |
| 연락처 | 845.5ms | 63ms | 92.5% |
| 홈 | 331ms | 63.5ms | 80.8% |

미리 받기가 완료된 개선 빌드에서는 클릭 이후 문서 요청의 전송량이 모두 0B였다. 미리 받기가 끝나기 전에 클릭하거나 데이터 절약 모드 등으로 미리 받기가 제한되면 문서를 받는 시간이 추가된다. 미리 받기는 방문하지 않을 메뉴의 HTML도 내려받을 수 있다. 실제 방문자 전체의 시간 분포는 별도 수집하지 않았다.

## 검증과 재현

- `npm run verify`: 타입 오류 0개, 단위 테스트 111개, 빌드, 공개 전 검사, 내부 링크 검사, 근거 ID 검사 통과.
- 데스크톱·모바일 브라우저 검사: 185개 통과, 기기 조건에 따라 9개 생략. 메뉴 이동, 뒤로 가기, 미리 받기, 즉시 표시, 경력 숫자 유지, 화면 전환 API가 없는 브라우저, 타이핑, 필터, 재생·멈춤, 동작 줄이기와 스크립트 없는 화면을 확인한다.
- 별도 읽기 전용 코드 검토 통과.

```sh
npm run verify
node scripts/serve-dist.mjs dist 4326
BASE_URL=http://localhost:4326 npm run test:e2e -- --workers=2
THROTTLE=1 node scripts/measure-navigation.mjs http://localhost:4326 /tmp/navigation.json
```

서버는 별도 터미널에서 실행한다. 측정 스크립트는 각 이동의 문서 준비·교체·화면 전환·등장 효과 완료 시점과 요청 전송량을 JSON으로 저장한다. 비교 빌드는 별도 디렉터리와 포트로 실행하고 같은 조건을 적용한다.
