# 포트폴리오 전송량과 화면 효과

확인 날짜: 2026-09-28. 비교 기준은 `a7d5080`의 운영 빌드와 성능 개선 작업 브랜치 `perf/faster-navigation`의 빌드다.

## 구조

- 공통 스타일과 글꼴 선언은 해시가 붙은 CSS 파일 하나로 배포한다. 홈과 경력 사이에서 같은 스타일을 다시 요청하지 않는지 브라우저 테스트로 확인한다.
- 홈의 타이핑과 경력 숫자는 Astro HTML과 브라우저 커스텀 엘리먼트로 제공한다. React 실행 코드를 받지 않는다. 페이지에서 제거되면 타이머, 화면 갱신 예약, 화면 진입 관찰자를 정리한다.
- 타이핑 순서와 숫자 계산은 `src/lib/typewriter.ts`, `src/lib/countup.ts`를 재사용한다. 스크립트가 없거나 사용자가 동작 줄이기를 선택하면 문구와 최종 숫자를 보여 준다.
- 프로젝트 필터, 재생형 그림, 결정표, 움직이는 이미지에는 React를 사용한다.
- 움직이는 화면은 애니메이션 WebP로 배포한다. 원본 GIF는 `src/assets/motion/`에 두고 `scripts/media/optimize.mjs`로 변환한다. 크기, 전체 재생 시간, 반복 설정을 검사하며 정지 이미지에 높은 다운로드 우선순위를 준다.

## 크기 비교

HTML은 압축 전 파일 크기다. 분리된 공통 CSS는 약 20KB로 압축 전송되며 페이지 사이에서 재사용한다.

| 항목 | 비교 기준 | 개선 결과 | 감소 |
| --- | ---: | ---: | ---: |
| 홈 HTML | 83,584B | 10,649B | 87.3% |
| 프로젝트 HTML | 116,659B | 47,395B | 59.4% |
| 경력 HTML | 93,603B | 18,117B | 80.6% |
| 홈 JavaScript 압축 전송량 | 66,775B | 5,562B | 91.7% |
| 움직이는 이미지 두 개 | 2,843,639B | 1,272,250B | 55.3% |
| 홈 전체 응답 본문 전송량 | 313,410B | 249,985B | 20.2% |
| 혜택홈 사례 전체 응답 본문 전송량 | 2,672,953B | 1,648,457B | 38.3% |

전체 전송량은 새 브라우저 컨텍스트에서 글꼴과 움직이는 이미지까지 모두 받은 뒤, 문서와 리소스의 `encodedBodySize`를 더했다. HTTP 헤더는 포함하지 않는다. 모바일 화면 390×844, 픽셀 배율 1.75, 왕복 지연 150ms, 다운로드 200,000B/s, CPU 속도 4배 제한으로 로컬 압축 서버에서 측정했다.

공통 CSS 분리는 첫 방문에 요청 하나를 추가한다. 단일 측정에서 주요 내용이 처음 그려지는 시간은 홈 360→516ms, 프로젝트 408→720ms, 혜택홈 사례 1,300→1,048ms였다. 전송량 감소를 모든 페이지의 첫 표시 시간 개선으로 해석하지 않는다. 페이지 이동에서는 공통 CSS를 재사용하고, 홈·경력에서 React 로딩과 초기 실행이 사라진다.

## 검증

- `npm run verify`: 타입 오류 0개, 단위 테스트 110개, 빌드, 공개 전 검사, 내부 링크, 근거 ID 검사 통과.
- 데스크톱·모바일 브라우저 검사: 타이핑, 숫자의 실제 0→최종값 변화, 메뉴 이동, 필터, 재생·멈춤, 버튼 포커스, 가로 넘침, 동작 줄이기, 스크립트 없는 화면 확인.
- 홈·경력·프로젝트·사례 화면을 모바일과 데스크톱 크기로 캡처해 확인.
- 별도 읽기 전용 코드 검토에서 지적한 숫자 효과 테스트의 잘못된 통과 가능성을 수정하고 재검증.

모바일 Lighthouse 13.4.1 결과는 각 페이지를 세 번 측정했다. 모든 실행에서 화면 응답을 막은 시간은 0ms였다.

| 페이지 | 성능 3회 | 접근성 | 검색 최적화 | 주요 내용 표시 시간 중앙값 |
| --- | --- | ---: | ---: | ---: |
| 홈 | 100 / 100 / 100 | 100 | 100 | 1.21초 |
| 프로젝트 목록 | 99 / 99 / 99 | 100 | 100 | 2.10초 |
| 혜택홈 사례 | 99 / 99 / 99 | 100 | 100 | 2.10초 |

Lighthouse의 시간은 시뮬레이션 기반이므로 위 브라우저 직접 측정 시간과 따로 읽는다.

## 재현

```sh
npm run verify
node scripts/serve-dist.mjs dist 4324
BASE_URL=http://localhost:4324 npm run test:e2e -- --workers=2
```

성능 점수는 같은 서버를 대상으로 Lighthouse 13.4.1의 모바일 기본 설정에서 홈, 프로젝트 목록, 혜택홈 사례를 각각 세 번 확인한다. 네트워크와 기기 상태에 따른 실제 방문자의 시간 분포는 별도 수집하지 않는다.
